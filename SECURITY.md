# Security

Please do not report credential exposure or other vulnerabilities in a public issue. If private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on the GitHub Security tab. Otherwise, contact the repository owner privately through GitHub before disclosure.

If a Louibot run exposes a credential, revoke or rotate it immediately, then preserve the relevant redacted job log and reproduction details for the private report. Do not include live tokens, private keys, or repository secrets in the report.
