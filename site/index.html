The loop

A narrow path from issue to review.

Louibot handles the repetitive middle while GitHub remains the collaboration surface your team knows.

01

Point it at an issue

Write the issue normally. Add one exact comment: @louibot implement. If a product decision is missing, Louibot pauses and asks focused questions first.

02

It prepares the workspace

A persistent Git worktree and disposable Docker sandbox keep the host and credentials out of the coding loop.

03

The agent does the work

It reads repository instructions, edits through one shell tool, installs dependencies, and runs discovered checks.

04

You review the draft

Louibot preserves your repository PR template, adds its summary and validation, and opens a draft. Submit inline feedback, then comment @louibot revise to continue the same work.

Why this shape

Useful without pretending to be autonomous.

Louibot is opinionated about the boundary: it can implement a small, well-defined issue, but it cannot invent product requirements, merge code, or quietly operate a server on your behalf.

↳

Local execution. Your repository, API keys, checkpoints, and logs stay on your machine.

↳

Explicit triggers. Humans start implementation and revisions with visible GitHub comments.

↳

Inspectable state. A small CLI shows active jobs, logs, costs, pauses, and failures.

Get started

Start from the repo you want to change.

Bring Node.js 22+, GitHub CLI, Docker, and an API key for a tool-calling model. Louibot identifies the repository from its GitHub origin; there is no setup command or config file to create.

terminalcopy / paste 
# install
npm install --global louibot

# from your repository root
export OPENAI_API_KEY="..."
louibot doctor --model openai/gpt-6-luna

# start polling GitHub
louibot start --model openai/gpt-6-luna
A

Use your own model key

OpenAI, Anthropic, and OpenAI-compatible Chat Completions endpoints are supported. Keys stay on the host. Pass provider, model, limits, labels, and sandbox options to start; YAML is optional for saved defaults.

B

Keep the issue small

Good inputs have a clear outcome, nearby tests, and repository instructions in AGENTS.md.

C

Stay in control

Louibot creates draft PRs and never merges them. Stop, inspect, retry, or close the work from the CLI or GitHub.
